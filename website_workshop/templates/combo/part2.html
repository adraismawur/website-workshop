In this case, I am even using a relatively safe method to call the programs wc and stat: 

        
    def call_program_safe(args):
        out = run(args, capture_output=True)

        if out.returncode != 0:
            output = out.stderr.decode("utf-8")
            raise RuntimeError(
                f"Failed to run {args} command: {output}"
            )

        return out.stdout.decode("utf-8")

I am not allowing users to input arguments. I am even transforming the input_file_path to a relative path, so that people do not see my username (this would otherwise print /home/secure-website/src/website-workshop/...) 

        
    program_result = call_program_safe([form.program.data, input_file_path.relative_to(Path.cwd())])
