In the previous pages, a form exposed an input field where you could enter your commands. Things are not always this simple however. In the form below, the options you can choose from are limited.

Try selecting one of these options and running the command:

{{ form.submit }}
{% if program_result %} 
            
{{ program_result }}

This runs just fine, but is only a little bit safe. There are some easy ways around this.

One way you can edit what gets sent through from this form is by not using this form at all. To do so, we will use a program called curl. This program should be installed by default on most operating systems, but if it is not, you can download it from this link: https://curl.se/download.html.

Open a terminal or a command prompt, and type in the following: 

            
    curl {{ request.url | replace('http', 'https') }} -F program=ls

Curl itself should give you a response telling you if it worked. The above should return something like this: 

            
    Hi! Here is the result of your CURL request:

    environment.yml
    secure-web.db
    website_workshop


    Looks like you sent the request correctly.

There are a few more commands that I can allow you to play with. Try the following commands:

  • neofetch
  • whoami

Consider what these commands tell you about the system and who operates it.

Finally, also try our good friend echo 

            
    curl {{ request.url | replace('http', 'https') }} -F program="echo hello, world!"
