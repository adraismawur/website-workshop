SQL injection part 1

SQL injection involves the execution of SQL statements on a database that are unexpected by a website or application. This can happen when there are no protections against custom input in forms, or if there are no protections when the SQL is actually executed.

In this exercise, you are going to execute some queries on this website's database through some insecure code.

Pay attention to the top of this page. Errors, warnings and information messages may pop up at the top.

If a red message shows up, you made a mistake somewhere
If a yellow message shows up, there was an expected error.
green message shows up, something normal happened.
