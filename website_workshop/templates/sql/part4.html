SQL injection part 4

We're logged in as admin! And we didn't even input the username! But how? Here is what you entered:

        
    ' or 1--

The single quote again closes the previous string

'or 1' is our own condition. It basically means "or true", which is always true.

-- again makes SQLite ignore the rest of the statement

As a result your query will look like this:

        
    SELECT * FROM users WHERE name = '' or 1--';

Which means we are selecting all users where one of the following is true:

  • The name is equal to ''
  • True

Since True is always True, we get every row.

Of course this will often not be this easy. People who (for good or bad reasons) try to access systems this way often take a lot longer and have much more complicated stuff up their sleeve.

SQL injection has been around for a long time, so systems have added protections to minimize mistakes that developers make to expose their websites to SQL injection vulnerabilities.
