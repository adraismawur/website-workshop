SQL injection part 5

We got a different error now: "You can only execute one statement at a time.". Turns out the database library we are using already has some form of security built-in: it really only expects one query at a time.

As a reminder, this was the query you put in:

        
    '; INSERT INTO users values ('test');--

And this was the code:

        
    try:
        r = db.execute("SELECT * FROM users WHERE name = " + form.username.data + ';').fetchone()
    except Error as e:
        flash('Failed to log in: ' + str(e), 'error')
As a result, we got the following SQL: 
        
    SELECT * FROM users WHERE name = ''; INSERT INTO users values ('test');--'

Two queries! Of course, since you have logged in as an admin you could probably add yourself in this imaginary application if you wanted to.

Let's try it again, except instead of the execute(query) command, I am using the executescript(query) command: 

        
    try:
        r = db.executescript("SELECT * FROM users WHERE name = '" + form.username.data.strip() + "';").fetchone()
    except Error as e:
        flash('Error: ' + str(e), 'error')

Enter something like this again, replacing test with something you will remember

        
    '; INSERT INTO users (name) values ('test');--

Make sure to replace test with something of your choosing!
