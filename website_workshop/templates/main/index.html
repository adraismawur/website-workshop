Welcome to the Secure website workshop... website

This website is the hands-on part of the workshop, where you will apply a few hacking techniques that you should try to avoid when creating a website.


It should go without saying that knowledge of this sort of thing should be wielded responsibly. Gaining access into computer systems without permission is obiviously illegal, so do not try these techniques on other websites.

This website is a personal website hosted by me for the duration of the workshop, so you have explicit permission to try whatever you want here.


Click on any of the chapters below to play around with exploiting this website.

Learn to replace unguarded shell commands
Learn to upload any file you want to an insecure file upload
