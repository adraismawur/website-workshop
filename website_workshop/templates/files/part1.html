Files part 1

You may have encountered a website (or have designed one) where users can upload their own data. For example, it is very common for a bioinformatician to supply a FASTA file or a genbank file for analysis. In these cases, it is very easy to allow users to upload data that you do not intend for them to upload, by not checking the input. This can lead to some dangerous situations.

Here's a form where a user is expected to input a FASTA file. It has a minor protection in that it will ask the browser to present a file selection dialogue showing only FASTA files:

Click to select FASTA file {{ form.file }}

But this does not prevent anyone from selecting files with a different extension; On most operating systems, this still allows you to select any file.

We can increase the protection by at least forcing the filename to end in .fa or .fasta: 

        
    def upload_file(form):
        filename = form.file.data
        is_fasta = filename.endswith(".fa") or filename.endswith(".fasta")
        if not is_fasta:
            flash("File is not a fasta file", "warning")

Try selecting a non-fasta file and pressing upload:

Click to select FASTA file {{ form.file }}
{{ form.submit }}

According to the above code, as long as a file has an extension ending in .fa or .fasta, it is a fasta file. But that is not actually correct. Fasta files are text files with a specific format, which the code is not checking for.

In actual applications, you will want to make sure that the content actually contains the format you expect. For fasta files, this is easy: they are expected to have information about a sequence with a preceding > character, and the sequence is limited to AUTCG.

There are plenty of python libraries that can make sure that whatever you are receiving is what you expect. In bioinformatics, Biopython's SeqIO is commonly used. You could use this to read a fasta file, and if it fails to read, delete the file.

But we won't do any of that on this website. Let's instead exploit this vulnerability to do some fun stuff.
